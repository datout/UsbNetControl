# Privacy policy

UsbNetControl is a local Windows administrative utility.

## Data collection

UsbNetControl does **not** collect, store, transmit or sell personal information. It does not include telemetry, analytics, advertising, crash reporting, online accounts or an automatic update checker.

**This program will not transfer any information to other networked systems unless specifically requested by the user or the person installing or operating it.**

## Local system information

To display and manage network adapters, UsbNetControl reads local Windows network-adapter and routing information. This information is used locally in the running process and is not uploaded anywhere.

To manage USB storage access, UsbNetControl reads and writes the local Windows removable-storage policy under `HKLM`.

## Network behavior

UsbNetControl does not initiate Internet or LAN connections. Enabling or disabling a network adapter changes the operating system's local network configuration but does not cause UsbNetControl itself to send data over the network.

## Third-party services

The distributed application does not require a cloud service or third-party account. GitHub and SignPath may be used by project maintainers to build, publish and code-sign release binaries; those services are not contacted by the installed/running UsbNetControl application.
